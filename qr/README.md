# Códigos QR de prueba (AP-26)

Cada artesanía tiene un QR con el texto `aleyleo:artesania:<id>`.
Al escanearlo desde el Catálogo (botón **Escanear QR**) se abre su detalle.

| Archivo | Contenido | Qué pasa al escanearlo |
|---|---|---|
| `qr-artesania-1-colgante.png` | `aleyleo:artesania:1` | Abre "Colgante Lapislázuli Cordillera" |
| `qr-artesania-6-paila.png` | `aleyleo:artesania:6` | Abre "Paila de Cobre" (si la admin la desactivó: "ya no está disponible") |
| `qr-artesania-16-manta.png` | `aleyleo:artesania:16` | Abre "Manta Chilota" |
| `qr-invalido-link.png` | `https://www.google.cl` | Mensaje "Este código QR no es de Ale y Leo" |

Para el video: abrir la imagen en el computador (o imprimirla) y apuntar la cámara del teléfono.
En el emulador se puede usar la cámara virtual (Extended controls → Camera → Virtual scene images).
